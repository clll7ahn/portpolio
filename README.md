# Portfolio - Skills Showcase

이 포트폴리오는 PPT 작성 및 프레젠테이션 관련 기술들을 포함한 전문 역량을 보여줍니다.

## 구조

- `skills.json`: 기술 및 역량 데이터
- `index.html`: 포트폴리오 웹 페이지

## 주요 스킬 카테고리

### 1. Presentation & Communication
- PowerPoint (PPT) 작성
- 프레젠테이션 디자인
- 비즈니스 커뮤니케이션
- 데이터 시각화

### 2. Office Productivity Tools
- Microsoft PowerPoint
- Google Slides
- Keynote
- Canva
- Prezi

### 3. Design Tools
- Adobe Creative Suite
- Figma

## 사용 방법

1. `skills.json` 파일에서 스킬 데이터를 확인할 수 있습니다.
2. `index.html` 파일을 브라우저에서 열어 포트폴리오를 확인할 수 있습니다.

## 업데이트

스킬을 추가하거나 수정하려면 `skills.json` 파일을 편집하세요.
